# theemalik pov

Website for **theemalik pov**, a Lagos-based photography studio founded in 2019.

The studio shoots weddings, birthdays and parties, portraits, family and maternity sessions,
graduations and events. The site is a single page covering the work gallery, the studio's story,
a motion reel, the services offered, how a shoot comes together, and how to get in touch.

- Instagram: [@theemalik_pov](https://www.instagram.com/theemalik_pov/)
- Email: hello@theemalikpov.com

## Requirements

Node 22 or newer.

## Running locally

```bash
npm install
npm run dev
```

The dev server prints a local URL (usually http://localhost:5173).

## Other commands

```bash
npm run build    # production build, output in dist/
npm run preview  # serve the production build locally
npm run lint     # lint the codebase
```
